## 目标
在 Skill 设置弹窗左侧分类侧边栏新增第二个分类「数据存储」，右侧展示当前 Skill 存储目录（`~/.prompt-clip/skills`），点击「在文件管理器中打开」按钮用系统文件管理器打开该路径。

## 现状分析
- Skill hub 存储目录在 Rust 端由 `SkillPaths::skills_dir()` 计算 = `$HOME/.prompt-clip/skills`（`src-tauri/src/skills/paths.rs:21`），由 `SkillPaths::initialize()` 创建。
- 前端已有 `skillsPath` 流转：`SkillService.scan()` 返回 → `skillStore.skillsPath`（`skillStore.ts:19,77`）。
- 已有「在文件管理器中显示」能力：Tauri 命令 `skill_reveal_external`（`commands.rs:52-62`）+ 私有 helper `reveal_in_file_manager`（`commands.rs:672-693`，跨平台 macOS `open -R` / Windows `explorer /select,` / Linux `xdg-open`）。**但 `skill_reveal_external` 只解析 agent 工具路径，不能打开 hub 目录**。
- Skill 管理整体仅桌面可用：所有 skill service 调用走 `requireDesktop()`（`skillService.ts:37`），Web 端会抛 `skill_desktop_only`。Web 端 `skillsPath` 为 `''`。

## 实现步骤

### 1. Rust：新增 `skill_reveal_hub` 命令（`src-tauri/src/skills/commands.rs`）
紧邻 `skill_reveal_external` 新增，复用 `reveal_in_file_manager` helper：
```rust
#[tauri::command]
pub fn skill_reveal_hub() -> Result<(), SkillManagerError> {
    let home_dir = home_directory()?;
    let paths = SkillPaths::new(&home_dir);
    paths.initialize()?;          // 确保目录存在，避免首次安装时打开失败
    reveal_in_file_manager(&paths.skills_dir())
}
```
在 `src-tauri/src/lib.rs:1036` 的 `invoke_handler` 中注册 `skills::commands::skill_reveal_hub`。

### 2. 前端 service：新增 `revealHubSkill`（`src/services/skillService.ts`）
仿照 `revealExternalSkill`（`skillService.ts:61-67`），加 `requireDesktop()` 守卫并 invoke 新命令，导出到 `SkillService` 对象：
```ts
export async function revealHubSkill(): Promise<void> {
  requireDesktop();
  await invoke('skill_reveal_hub');
}
```

### 3. i18n：新增 4 语言文案（`src/i18n/messages.ts`，`t.skills` 命名空间）
- `storageTab`: 数据存储 / 資料儲存 / Storage / データ保存
- `storageDescription`: 说明性文字，如「PromptClip 将所有 Skill 保存在本地文件夹中。」
- `storagePath`: 存储位置 / ...
- `storageOpen`: 在文件管理器中打开 / ...
- `storageOpenFailed`: 打开失败，请重试。/ ...（错误兜底，与 `externalScanError` 风格一致）

### 4. 改造 `SkillSettingsModal.tsx`
- 扩展 `SkillSettingsTab` 类型：`'sync' | 'storage'`。
- 侧边栏 nav 新增第二个分类按钮「数据存储」，图标复用已在字体子集中的 `folder` 图标（先确认 `folder` 在 `scripts/icon-glyphs.txt`；若不在则用已有的 `save` 或 `database`，最终以子集清单为准——如需新增图标则按 AGENTS.md 跑子集脚本）。
- 新增 props：
  - `skillsPath: string`（展示用）
  - `onRevealStorage: () => void`（点击打开回调，错误处理由 SkillManagerPage 统一包装，沿用 `onRevealExternal` 模式）
- 新增右侧「数据存储」内容区：展示 `skillsPath`（`<code>` 样式，可换行 break-all）+ 「在文件管理器中打开」按钮（`onRevealStorage`）。当 `skillsPath` 为空（Web 端）时隐藏打开按钮或置灰，并显示说明文字「数据存储仅在桌面版中可用」。
- footer（取消/保存）保持不变——「数据存储」分类无保存动作，按钮仍触发同步设置的 onSave（与现有行为一致，保存只对同步设置生效）。

### 5. `SkillManagerPage.tsx` 接线
- 从 `useSkillStore` 取 `skillsPath`（store 在 `load()` 时已填充），传入 modal。
- 新增 `revealStorage` handler，包装 `SkillService.revealHub()`，错误时 `setOperationError(true)`（与现有 `revealExternal` handler 风格一致，`SkillManagerPage.tsx:80-87`），作为 `onRevealStorage` 传入 modal。
